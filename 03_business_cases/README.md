# 03 练习：Kaggle样本数据集

本章使用Kaggle的开放样本数据集进行SQL业务案例实操

数据来源：https://www.kaggle.com/datasets/blastchar/telco-customer-churn

**目标：** 学习主要语法、完成业务问题、生成可视化报告

---

## 本章内容

**用户流失综合分析.md**：以「哪类用户会流失，为什么？」为业务问题，完整演示从问题拆解到SQL查询到数据解读的全流程

业务问题拆解：

```
大问题：哪类用户会流失，为什么？
  ├── 用户画像分析    → 流失用户长什么样（人口特征）
  ├── 套餐与留存分析  → 套餐类型和使用时长如何影响流失
  └── 综合结论        → 产品建议
```

---

## 本章新学语法

| 语法 | 作用 | 使用场景 |
|------|------|----------|
| WHERE | 条件筛选 | 只看流失用户、筛选特定套餐 |
| AVG() | 求平均值 | 计算平均使用时长、平均月费 |
| COUNT DISTINCT | 去重计数 | 统计不重复的用户数 |
| LEFT JOIN | 保留左表所有数据的关联 | 和INNER JOIN的区别 |
| 子查询 | 两步走的复杂分析 | 找出高于平均月费的流失用户 |
