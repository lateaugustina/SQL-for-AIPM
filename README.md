# SQL for AIPM

---

## 关于这个仓库

在0基础的AIPM自学之旅中，意识到在AI开始帮PM写SQL的今天
AIPM真正需要的不是「会写」，而是「会审查」和「会整合工具」

于是结合自身学习思路，整理了从0开始、以AIPM能力模型为导向学习SQL的过程
区别于技术向、通用型的SQL课程，这是一系列适合0基础/PM转行,以业务问题驱动，强调审查能力训练
覆盖从语法入门到AI工作流整合的核心经验分享
所有练习都从真实业务问题出发，不是语法手册~

亲测0基础可轻松入门

**适合谁看：** 0基础AIPM转行者、希望系统建立数据分析能力的产品经理

## AIPM常用SQL语法

| 语法                   | 业务场景示例             |
| -------------------- | ------------------ |
| SELECT + WHERE       | 找出某类用户、某段时间的数据     |
| GROUP BY + COUNT/SUM | 计算DAU、转化率、收入       |
| JOIN                 | 将用户表、行为表、订单表拼在一起分析 |
| CASE WHEN            | 用户分层、功能归类          |
| 子查询                  | 找出消费高于平均水平的用户      |
